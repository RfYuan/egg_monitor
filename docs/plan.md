## （一）期货盘面API（核心，全部可自动抓取，优先对接）
聚焦鸡蛋JD2607/JD2609，同时覆盖玉米、豆粕等饲料品种，支持行情、仓单、持仓、公告。
### 1. 大连商品交易所官方API（首选，权威免费，鸡蛋主力交易所）
- 地址：http://www.dce.com.cn → 数据服务 → API服务（需注册大商所对外门户账号，免费申请接口权限）
- 可获取数据：
  1.  期货日/周/月行情（开盘价、收盘价、结算价、成交量、持仓量）；
  2.  仓单日报（鸡蛋仓单数量、仓单增减，核心库存指标）；
  3.  前20会员持仓数据（多空主力增减仓）；
  4.  交易所公告（保证金调整、提保、风控规则、节假日安排）。
- 更新频率：行情/仓单**每日盘后更新**；持仓**每周五更新**；公告实时推送。
- 接入语言：HTTP RESTful，支持Python requests调用，文档官方齐全。
- 适用场景：盘面核心数据自动化采集，判断资金、库存、交易所风控变动。

### 2. TqSdk（天勤量化，免费基础版，行情最强，个人用户首选）
- 官网：https://www.tqsdk.com/ ，开源Python SDK，**基础行情永久免费**
- 可获取数据：
  1.  实时盘口、Tick、1min/5min/1h/K线全周期行情；
  2.  合约基础信息（合约乘数、保证金标准、手续费标准）；
  3.  全市场期货品种行情（鸡蛋+玉米+豆粕一站式获取）。
- 特点：无需复杂配置，一行代码拉取数据，腾讯云服务器部署零压力；Tick数据付费，**日常监测只用K线/盘口完全免费**。
- 代码示例（极简）：
```python
from tqsdk import TqApi, TqAuth
api = TqApi(auth=TqAuth("你的账号", "你的密码"))
quote = api.get_quote("DCE.jd2609")  # 获取鸡蛋JD2609实时行情
print(quote.last_price, quote.volume, quote.open_interest)
```

### 3. AKShare（开源免费财经库，零门槛，补充行情+部分现货）
- 项目地址：https://github.com/akfamily/akshare ，纯Python开源，无需API Key，本地运行抓取网页接口
- 可获取：国内期货全品种K线、历史行情、部分大宗商品现货报价。
- 优势：安装即用（`pip install akshare`），适合新手快速搭建数据脚本，作为TqSdk备用数据源。

### 4. Tushare（补充历史行情，需积分）
- 官网：https://tushare.pro/ ，注册送基础积分，免费满足低频历史数据查询
- 能力：期货历史日线、主力合约映射，适合回溯历史季节性行情，辅助复盘。

## 四、腾讯云服务器部署规划（人工跑通后，分步自动化）
你的腾讯云服务器（Linux系统优先，Python环境），分「基础环境→脚本部署→数据存储→定时任务」四步，循序渐进，不一步到位。
### 1. 基础环境准备（一次性配置）
1.  安装Python3、pip、常用库：
    ```bash
    pip install tqsdk akshare requests beautifulsoup4 sqlite3
    ```
2.  搭建本地数据库：优先轻量**SQLite**（无需额外服务，适合个人监测），存储每日/每周指标数据；后期数据量大再升级MySQL。
3.  目录规划（清晰分类，方便维护）：
    ```
    /egg_future/
    ├── data/        # 存放CSV/Excel人工报表、数据库文件
    ├── script/      # 自动化API脚本（行情、现货、爬虫）
    ├── log/         # 每日运行日志、交易记录
    └── report/      # 每周/每月汇总报告
    ```

### 2. 分步自动化（按优先级，先易后难）
#### 第一步（最高优先级）：期货行情自动化脚本
对接**TqSdk + 大商所API**，实现：每日自动抓取JD2609行情、仓单、持仓，写入SQLite数据库。
- 运行频率：**交易日 9:00、15:40 各执行一次**（盘前+盘后）；
- 腾讯云定时：使用`crontab`设置定时任务，无人值守运行。

#### 第二步：现货价格半自动
用AKShare+简易爬虫抓取鸡蛋、玉米、豆粕现货，每日10:00执行一次；产业报告（存栏/鸡苗）继续**人工上传CSV**到服务器`data`文件夹。

#### 第三步：预警自动化（进阶）
在脚本中嵌入**预警阈值规则**，例如：
- 价格跌破3750 → 脚本输出「触发止损预警」；
- 仓单环比+20% → 输出「仓单利空预警」；
可搭配邮件/企业微信机器人推送预警消息。

#### 第四步（可选）：产业报表爬虫
针对卓创、钢联周报，开发低频合规爬虫（每日1次），替代人工下载，**严格控制抓取频率，避免封禁IP**。

### 3. 服务器运维&安全（个人监测重点）
1.  接口密钥、账号密码：存放在服务器本地配置文件，禁止硬编码、禁止外传；
2.  抓取频率：所有爬虫/API请求**低频为主**（最短间隔5分钟），合规使用数据源；
3.  数据备份：每周备份一次SQLite数据库和日志，防止数据丢失；
4.  权限：仅自己登录服务器，关闭多余端口。

## 五、补充建议&避坑点
1. **现阶段核心：人工优先**
   产业数据（存栏、鸡苗）暂无成熟API，不要执着于全自动化，**先靠人工吃透指标逻辑、熟悉预警场景**，自动化只是提升效率的工具。
2. **API选型避坑**
   - 不要使用不知名免费行情API（稳定性差、数据延迟），坚守**大商所、TqSdk、AKShare**三大主流；
   - 卓创、我的农产品网等付费行业数据，个人用户无需采购，免费周报足够使用。
3. **结合你的交易策略联动**
   所有监测指标最终服务于4套投资方案：
   - 纯期货：严格执行价格止损+供应端二级预警清仓；
